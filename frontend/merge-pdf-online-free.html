How to do it

  1. Open Merge PDFs and drop your PDF files. Up to 10 files, 30 MB in total.
  2. Check the order. The merged file follows the order you add the files in.
  3. Click Merge PDFs.
  4. Download the merged PDF.

Good to know

  • Order matters. Add the files in the order they should appear.
  • Need only some pages from each file? Use the PDF Organizer first to extract those pages, then merge.
  • If the merged file is too large for a portal, run it through the PDF Organizer with a maximum size in KB.
