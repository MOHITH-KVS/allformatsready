Compress a PDF to a Target Size (KB)

Many portals reject a PDF that is even a little over the limit. The AllFormatsReady PDF Organizer lets you type the maximum size in KB and gives you a PDF that fits, free and with no sign-up.

Open the PDF Organizer →

How to do it

  1. Open the PDF Organizer and drop your PDF (up to 10 MB).
  2. Type the size limit in the Max size (KB) box, for example 200. Any value from 20 to 10240 KB works.
  3. Leave Pages empty to keep every page, or enter pages such as 1-3,5.
  4. Click Create PDF and download the result.

Good to know

  • The tool first tries a lossless clean-up. Only if the file is still too big does it turn pages into images to reach your target, and then the text can no longer be selected. A notice tells you when this happens.
  • Ask for a realistic size. A 40-page colour scan cannot become 20 KB without becoming unreadable. If the target cannot be reached, the tool tells you the smallest size it got.
  • Need only some pages? Enter them in the Pages box first: fewer pages means a smaller file with better quality.

Frequently asked questions

How do I reduce a PDF to 100 KB?

Open the PDF Organizer, drop the file, type 100 in Max size (KB) and click Create PDF. If 100 KB is not reachable, the tool shows the smallest size it achieved.

Will the quality drop?

Only when the PDF has to be converted to images to reach the size you asked for. Text-based PDFs often shrink without any visible change.

Is there a file size limit?

You can upload a PDF up to 10 MB.
